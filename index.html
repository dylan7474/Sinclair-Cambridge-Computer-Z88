Sinclair Cambridge Z88 Operating Manual

1. The Z88 System Keys

  • INDEX: The task manager key. Press anytime to suspend current task and swap between BBC BASIC, PipeDream, Calculator, and Filer.
  • MENU: Reveals the top command menus for the active application.
  • HELP: Displays instant on-screen help.
  • ◇ (Diamond): Green modifier key used for quick command shortcuts (e.g. ◇B for BASIC, ◇P for PipeDream).
  • □ (Square): Secondary modifier key for special symbols and formatting.

2. BBC BASIC Commands

Type these directly into BBC BASIC and press ENTER:

RUN - Execute program
LIST - List program lines
NEW - Clear current program
CLS - Clear LCD screen
PLOT 69, x, y - Draw point
LINE x1, y1, x2, y2 - Vector

3. The Iconic Z88 Page Map

The right portion of the 640×64 super-twist screen renders the world's first miniature visual document preview, showing page density and margins in real-time as you type in PipeDream!
